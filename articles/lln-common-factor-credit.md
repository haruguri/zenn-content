「1万件も貸し出せば、貸倒率は正確に読める」。銀行の与信の説明でよく出てくる言い方です。

[前の記事](https://zenn.dev/haruguri/articles/lln-without-independence-polling)では、世論調査を例に、回答が束（クラスター）になっていると大数の法則の効きが遅れること、しかし束が有限なら最終的には真の値に着くことを見ました。鍵は「人数を増やすと平均相関がゼロに向かう」ことでした。

この記事では、平均相関がゼロに向かわない場合を扱います。全員が同じ1回の引きを共有しているとき、平均は落ち着くのに真の値には着かない。式は前の記事と同じ1本で、違いは極限だけです。例は貸倒率（1件ごとの貸し倒れの有無の平均）にします。

## 1本の式と、2つの極限

$n$ 件の貸し倒れ $X_1,\dots,X_n$（貸し倒れなら1）が、各々分散 $\sigma^2 = p(1-p)$ をもち、相関の平均が $\bar\rho_n$ だとします。標本平均の分散は

$$
\mathrm{Var}(\bar X_n) = \frac{\sigma^2}{n}\bigl(1 + (n-1)\bar\rho_n\bigr)
$$

です（導出は前の記事）。$n\to\infty$ の振る舞いは $(n-1)\bar\rho_n$ の行き先で決まります。

- **$(n-1)\bar\rho_n$ が有限で止まる**：束が有限（束の大きさ $m$ 固定）なら $\bar\rho_n \approx (m-1)\rho/(n-1)$ で、括弧の中は $1+(m-1)\rho$ に収束。分散は $1/n$ で消える。前の記事の世界です。
- **$\bar\rho_n = \rho > 0$ のまま**：全員が同じ束なら $(n-1)\rho$ は $n$ と同じ速さで育ち、

$$
\mathrm{Var}(\bar X_n) \;\longrightarrow\; \rho\,\sigma^2 \quad (n\to\infty)
$$

分散は消えず、底値 $\rho\sigma^2$ で止まる。これが今回の世界です。

数学的に言えば、前者は $\bar X_n$ が定数 $p$ に収束し、後者は $\bar X_n$ が**確率変数**に収束します。平均は落ち着くが、落ち着く先が毎回違う。

## 共通因子で相関を作る：Vasicek 一因子モデル

等相関 $\rho$ の二値変数を作るには、前の記事の Beta 混合（$p_k \sim \mathrm{Beta}$ を引いて全員に配る）でも構いませんが、貸倒率 2% のような稀な事象では、答えの相関を 0.05 以上にすると $p_k$ の分布が「ほぼ0か、たまに大きい」の二極になり、絵になりません。実務の値はもっと小さく、与信で標準的な Vasicek の一因子モデルがそのまま使えます。

$$
A_i = \sqrt{\rho_A}\,Z + \sqrt{1-\rho_A}\,\varepsilon_i,\qquad X_i = \mathbf 1\{A_i < \Phi^{-1}(p)\}
$$

$Z$ が全員で共有する**共通因子**（その年の景気）、$\varepsilon_i$ が個別要因、$\rho_A$ は資産相関です。$Z$ を1回引いたあとの条件付き貸倒率は

$$
p(Z) = \Phi\!\left(\frac{\Phi^{-1}(p) - \sqrt{\rho_A}\,Z}{\sqrt{1-\rho_A}}\right)
$$

で、$Z$ を固定すれば $X_i$ は独立です。「1回だけ引かれた値のもとでは独立」という構造が、そのまま式になっています。

注意したいのは、$\rho_A$ は潜在変数 $A$ の相関であって、$X$（答え）の相関ではないことです。答えの相関は

$$
\rho_X = \frac{\Phi_2\bigl(\Phi^{-1}(p),\Phi^{-1}(p);\rho_A\bigr) - p^2}{p(1-p)}
$$

で、$p=2\%$ では次の表のように一桁小さくなります。規制資本で「住宅ローンの相関 0.15」と言うときの 0.15 は $\rho_A$ の方です。

| 資産相関 $\rho_A$ | 答えの相関 $\rho_X$ | 底値 $\sqrt{\rho_X\sigma^2}$（SD, %） |
|---|---|---|
| 0 | 0 | 0 |
| 0.05 | 0.007 | 1.14 |
| 0.10 | 0.015 | 1.70 |
| 0.15 | 0.024 | 2.18 |

```python
from scipy.stats import norm, multivariate_normal
p = 0.02; k = norm.ppf(p)
def defcorr(ra):
    p12 = multivariate_normal(mean=[0, 0], cov=[[1, ra], [ra, 1]]).cdf([k, k])
    return (p12 - p * p) / (p * (1 - p))
def cond_pd(z, ra):
    return norm.cdf((k - np.sqrt(ra) * z) / np.sqrt(1 - ra))
```

## 実験1：ここまでの貸倒率の軌跡

真の貸倒率 2%、1万件まで、8試行。$Z$ を試行ごとに1回引き、その $p(Z)$ で1万件を独立に引きます。赤は2,000本のシミュレーションの 2.5〜97.5% 分位です。

![図1。資産相関を0・0.05・0.10・0.15と変えたときの、ここまでの貸倒率の推移。独立では1万件で2%の±0.3ポイントに収まるが、相関があると8本はそれぞれ別の値で落ち着き、赤の幅は件数を増やしても縮まらない。](/images/lln-common-factor-credit/fig1.png)
*図1：真の貸倒率 2%、各8試行。左上は独立、残りは共通因子あり。赤はシミュレーション2,000本の 2.5〜97.5% 分位。*

独立の枠は1万件で 1.7〜2.3% に収まります。相関のある枠は、8本とも途中から動かなくなるのに、落ち着く先が 0.1% から 6% まで散らばる。赤の幅は1万件でも閉じません。

帯が上に長い非対称なのは、$p(Z)$ の分布が右に裾を引くからです（$Z$ が悪い方に出たときの貸倒率は、良い方に出たときより大きく動く）。正規近似の $\pm1.96\,\mathrm{SD}$ では下側が 0 を割り、上側を線が突き抜けます。

## 実験2：強さではなく、薄まるかどうか

「相関があると縮まらない」ではありません。前の記事の束 1,000 人は相関 0.1 でも最終的に縮みました。縮まるかどうかを分けるのは、相関の強さではなく、$n$ を増やしたときに平均相関が薄まるかどうかです。

それを1枚で見るために、標本平均の標準偏差を $n$ に対して両対数で描きます。等相関4本は理論式、黒の破線は「隣とは強く相関し、離れるほど減衰する」AR(1) 型です。

AR(1) 型は、潜在変数を $A_i = \phi A_{i-1} + \sqrt{1-\phi^2}\,\varepsilon_i$（$\phi=0.98$）とし、同じ閾値で二値化しました。$|i-j|$ 離れた2件の潜在相関は $\phi^{|i-j|}$ で、隣同士の答えの相関は 0.80 と、等相関の例のどれよりはるかに強い相関です。しかし遠い件とは相関がないので、平均相関は $n$ とともにゼロへ向かいます。

![図2。標本平均の標準偏差を貸出件数に対して両対数で描いたもの。独立は傾き−1/2の直線、等相関3本は途中で水平になり底値で止まる、AR(1)型は最初は高いが傾き−1/2で下がり続け、1万件の手前で等相関の線を下へ突き抜ける。](/images/lln-common-factor-credit/fig2.png)
*図2：貸倒率の標準偏差 vs 件数。等相関（実線）は底値で止まる。AR(1) 型（破線）は隣との相関 0.80 と強いが、減衰するので $1/\sqrt n$ で縮み続け、1万件の手前で等相関 0.007 の線を下へ抜ける。点線は各等相関の底値。*

AR(1) 型は 1,000 件で 2.3%、1万件で 0.86% と、独立の $1/\sqrt n$ と同じ傾きで縮み続けます（独立の約6倍の幅ではあるので、実効件数は 1/36 程度）。等相関 0.007 は 1,000 件を過ぎたあたりで 1.15% に張り付いたまま。どちらが「強い相関」かと言えば AR(1) 型ですが、耐えられなくなるのは等相関の側です。

## 何が言えなくなり、何がまだ言えるか

言えなくなるのは、「件数を増やせば真の値に着く」です。$Z$ が1回しか引かれない以上、件数は $Z$ の不確かさを一切減らしません。

まだ言えるのは、**条件付きの**大数の法則です。$Z$ を固定すれば $X_i$ は独立なので、$\bar X_n \to p(Z)$ は $1/\sqrt n$ の速さで成り立つ。「今年の景気のもとでの貸倒率」は1万件あれば ±0.3 ポイントで読めます。分からないのは $p(Z)$ がどう散らばるか、つまり $Z$ の分布の方で、それを知るには $Z$ を複数回引く（複数の年、複数の市場）しかありません。

少し一般化すると、これは de Finetti の定理の構図です。無限列が交換可能（並べ替えても分布が変わらない）なら、それは「あるパラメータ $\theta$ を1回引いて、そのもとで i.i.d.」の混合として書けます。等相関の列は交換可能なので、標本平均が収束する先は定数ではなく $\theta$（ここでは $p(Z)$）です。「独立の崩れ（相関）」と「同一分布の崩れ（$\theta$ を1回引いて固定）」が同じものの裏表だ、というのがこの定理の言っていることで、このシリーズの第5回で戻ってきます。

## 参考：負の相関では崩れない

相関がゼロでないときに崩れるなら、負の相関でも崩れるのか。答えは「崩れない。負の側には縮む効果しかない」です。

$n$ 個の変数の平均相関には下限があります。合計の分散が負になれないことから

$$
\bar\rho_n \;\ge\; -\frac{1}{n-1}
$$

で、全員が互いに負に相関し続けることはできず、$n$ を増やすと負の平均相関は自動的にゼロへ向かいます。共通因子は分散を上にしか押せない、という非対称性です。

下限をちょうど達成するのが非復元抽出です。母集団 $N$ 件から $n$ 件を引くと、任意の2件の相関は $-1/(N-1)$ で、標本平均の分散は

$$
\mathrm{Var}(\bar X_n) = \frac{\sigma^2}{n}\cdot\frac{N-n}{N-1}
$$

（有限母集団修正）。$n = N$ で誤差はゼロになります。

![図3。非復元抽出の標準偏差を独立の場合との比で描いたもの。n が母集団の1割を超えるあたりから比が1を下回り、n＝N で0に落ちる。](/images/lln-common-factor-credit/fig3.png)
*図3：母集団 10,000 件からの非復元抽出。縦軸は独立（復元抽出）のときのぶれを1とした比。理論 $\sqrt{(N-n)/(N-1)}$ とシミュレーションが一致し、$n=N$ でゼロ。*

```
== 負の相関：平均相関の下限 −1/(n−1)。n=10,000 で -0.000100 ==
  非復元 n=5,000: 理論 0.109  実測 0.105  n=N: 理論 0 実測 0.000
```

層化抽出や対照変量法は、この負の相関を意図的に作って $1/\sqrt n$ より速く縮める技術です。前の記事で「束の中で似ないようにする」と書いたのは、この端の話でした。
