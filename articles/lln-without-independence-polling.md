「1,000人に聞けば誤差は±3ポイント」。世論調査の説明でよく出てくる数字です。この数字は大数の法則から出てきますが、前提が一つあります。**1,000人の答えが互いに独立であること**です。

この記事では、その前提を外します。独立が崩れる入り方を4通り用意して、標本平均（賛成率）がどう落ち着くかをシミュレーションで見て、最後に全部が1本の式に乗ることを確かめます。数式は出しますが、式が出るたびにコードで検証します。

なぜ独立が崩れるのか、という前提の側の話は、IntereStat のコラム[「1,000人の世論調査は、本当に1,000人分か」](https://www.interestat.jp/columns/yoron-chousa-taisuu-housoku)に書きました。ここでは崩れたあとに何が起きるかだけを扱います。

## 実験の枠

答えは賛成＝1・反対＝0 の二値、真の賛成率は 50% に固定します。1人ずつ聞く人数を増やしながら「ここまでの賛成率」を描き、同じ実験を8回繰り返して8本の線にします。上限は 20,000 人。

コードは numpy と matplotlib だけで、乱数は `default_rng(2026)` を1回だけ初期化して使い回します。全体は1ファイルで、末尾にリンクを置きます。ここでは生成機構の部分だけ抜き出します。

```python
import numpy as np
rng = np.random.default_rng(2026)
P = 0.5  # 真の賛成率

def running_mean(x):
    return np.cumsum(x) / np.arange(1, len(x) + 1)
```

## 実験1：独立（基準）

各人が独立に確率 0.5 で賛成します。

```python
def sample_independent(n, p=P):
    return rng.random(n) < p
```

図1の左上がこれです。1,000人の時点で ±3.2 ポイント（理論の ±2σ）に収まり、以降は √n の速さで縮み続けます。ここが基準線です。

## 実験2：束（クラスター）

出口調査や面接調査は、1,000人を全国から1人ずつ選ぶのではなく、地点を選んでその中でまとめて聞きます。同じ地点で聞かれた人たちを「束」と呼びます。束の中の人は、その日その町の空気を共有しているので、答えが似ます。

これを、束ごとに賛成率 $p_k$ を引き、束の中の各人は $p_k$ で賛成する、という2段階で作ります。$p_k$ を $\mathrm{Beta}(a, a)$ から引くと、束の中の2人の相関（級内相関）は

$$
\rho = \frac{\mathrm{Var}(p_k)}{p(1-p)} = \frac{1}{2a+1}
$$

になるので、狙った $\rho$ から $a = (1/\rho - 1)/2$ を逆算します。

```python
def sample_cluster(n, m, rho, p=P):
    """1束 m 人。束の中の相関は rho。"""
    k = -(-n // m)                      # 束の数（切り上げ）
    a = (1 / rho - 1) / 2
    p_k = rng.beta(a, a, size=k)        # 束ごとの賛成率
    return (rng.random((k, m)) < p_k[:, None]).ravel()[:n]
```

図1の右上が1束100人・相関0.1、左下が1束1,000人・相関0.1です。

![独立が崩れる入り方と、賛成率の落ち着き方](/images/fig1_panels.png)
*図1：左上から順に、独立／束100人／束1,000人／減衰する相関φ=0.98。各8試行、赤は理論の±2σ、縦の破線は1,000人の時点。*

右上（束100人）は、1,000人の時点で ±10.4 ポイント。独立の3倍以上です。左下（束1,000人）は ±31.8 ポイント。1,000人がまるごと一つの束なので、8本の線はそれぞれの束の癖に張り付いて平らになり、2束目が入ってから動き出します。

ただし、どちらも右端では 50% に向かっています。**着く場所は変わらず、着く速さだけが落ちている**。これが束の効き方です。

## 実験3：束の効き目は「人数 × 相関」で決まる

束の中の人数 $m$ と相関 $\rho$ を別々に振って、1,000人が実質何人分かを実測してみます。「何人分か」は、独立なら $p(1-p)/n$ になるはずの分散を実測の分散で割った値です。

![束の効き目は、1束の人数と束の中の相関の積で決まる](/images/fig2_m_rho.png)
*図2：左は相関ごとに m を振ったもの。右は横軸を (m−1)×相関 に取り直したもの。線は理論、点は400試行の実測。*

左の図では相関ごとに別の線になりますが、横軸を $(m-1)\rho$ に取り直すと（右の図）、全部が $1000/(1+x)$ の1本に重なります。束を小さくするのと、束の中で似ないようにするのとで、効き目は同じです。100人の束で相関0.1なら、1束はおよそ9人分。

標本設計ではこの $1+(m-1)\rho$ を「設計効果」と呼びます。1地点50人・相関0.1なら約5.9倍で、1,000人は170人分です。

## 実験4：減衰する相関

束は「同じ束の中では似る、束が違えば独立」でした。相関の入り方はもう一つあります。隣は似る、少し離れると少し似る、遠くなるとほぼ独立──距離で減衰する相関です。同じ調査員が続けて聞く、同じ日に聞く、といった状況が近い。

これは二値のマルコフ連鎖で作れます。前の人と同じ答えになる確率を $(1+\varphi)/2$ にすると、定常分布は (0.5, 0.5)、$k$ 人離れた2人の相関はちょうど $\varphi^k$ になります。

```python
def sample_decaying(n, phi, p=P):
    """前の人と同じ答えになる確率 (1+phi)/2。k人離れた相関は phi**k。"""
    flips = rng.random(n) >= (1 + phi) / 2   # True なら前の人と逆の答え
    flips[0] = rng.random() < p               # 先頭だけ直接引く
    return np.cumsum(flips) % 2 == 1          # 反転の回数の偶奇 = 今の答え
```

図1の右下が $\varphi = 0.98$ です。1,000人の時点で ±30.7 ポイント。左下の「束1,000人」とほぼ同じ幅です。

ここで図1の下段2枚を見比べてください。1,000人時点のばらつきはほぼ同じなのに、線の形が違います。束は平らな段になって、束が切り替わるところで跳ぶ。減衰する相関は、段にならずにゆっくり漂う。**崩れ方は違う。でも、あとで見るように、ばらつきの量は同じ式で決まっています。**

## 1本の式

ここまでの4実験を1本にまとめます。答え $X_1, \dots, X_n$ の分散を $\sigma^2$、$i$ 番目と $j$ 番目の相関を $\rho_{ij}$ とすると、標本平均の分散は共分散の総和で

$$
\mathrm{Var}(\bar X) = \frac{1}{n^2}\sum_{i}\sum_{j}\mathrm{Cov}(X_i, X_j)
= \frac{\sigma^2}{n}\Bigl(1 + (n-1)\,\bar\rho\Bigr),
\qquad
\bar\rho = \frac{1}{n(n-1)}\sum_{i \ne j}\rho_{ij}
$$

です。$\bar\rho$ は全員の組について相関を平均したもの（平均相関）。独立なら $\bar\rho = 0$ で、いつもの $\sigma^2/n$ に戻ります。

束の場合、同じ束に入る組の割合は $(m-1)/(n-1)$ なので $\bar\rho = \rho\,(m-1)/(n-1)$。括弧の中は

$$
1 + (n-1)\bar\rho = 1 + (m-1)\rho
$$

で、$n$ によらない定数になります。これが実験3で見た設計効果です。

減衰する相関の場合は $\rho_{ij} = \varphi^{|i-j|}$ なので、

$$
1 + (n-1)\bar\rho = 1 + \frac{2}{n}\sum_{k=1}^{n-1}(n-k)\,\varphi^k
\;\xrightarrow{\;n\to\infty\;}\;
\frac{1+\varphi}{1-\varphi}
$$

です。$\varphi = 0.98$ なら 99。つまり 1,000人が約10人分。$\varphi = 0.8$ なら 9 で、約110人分。

どちらの場合も、括弧の中は $n$ を増やしても定数に留まります。だから $n$ で割る分だけは効いて、遅れても着く。**独立が崩れても、平均相関がゼロに向かうかぎり、大数の法則は速さを失うだけで行き先は失わない。**

これを実測と突き合わせます。9通りの入り方で、1,000人の平均を2,000回ずつ取り、分散から「何人分か」を出しました。

## 何が言えなくなり、何がまだ言えるか

言えなくなるのは、誤差が $\sqrt{n}$ で縮むという速度の見積もりです。「1,000人だから±3」は、束の作り方と相関の入り方を見ずには言えません。

まだ言えるのは、行き先です。束の選び方に偏りがなく、相関が距離か束で切れているかぎり、平均は真の値に着きます。そして速度の方も、平均相関さえ見積もれれば $1 + (n-1)\bar\rho$ で補正できる。実務が設計効果を使っているのはそのためです。

ただし、この記事で扱ったのは「平均相関がゼロに向かう」場合だけです。1,000人全員が一つの束で、しかも人数を増やしても束が増えない──平均相関がゼロに向かわない──とき、式の括弧の中は $n$ とともに育ちます。そこでは平均は落ち着くのに、真の値ではない場所に落ち着く。それは別の記事にします。
