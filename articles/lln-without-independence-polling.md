「1,000人に聞けば誤差は±3ポイント」。世論調査の説明でよく出てくる数字です。この数字は大数の法則から出てきますが、前提が一つあります。**1,000人の答えが互いに独立であること**です。

この記事では、その前提を外します。世論調査で実際に起きる崩れ方──束にして聞く──をコードで作り、束の大きさと束の中の相関を変えながら、標本平均（賛成率）がどう落ち着くかを見て、最後に全部が1本の式に乗ることを確かめます。

同じ話を、具体例を交えて式を最小限にして書いたものが、IntereStat のコラム[「1,000人の世論調査は、本当に1,000人分か」](https://www.interestat.jp/columns/yoron-chousa-taisuu-housoku)にあります。この記事はその計算編です。

## 実験の枠

答えは賛成＝1・反対＝0 の二値、真の賛成率は 50% に固定します。1人ずつ聞く人数を増やしながら「ここまでの賛成率」を描き、同じ実験を8回繰り返して8本の線にします。上限は 20,000 人。

コードは numpy と matplotlib だけで、乱数は `default_rng(2026)` を1回だけ初期化して使い回します。全体は1ファイルで、末尾にリンクを置きます。ここでは生成機構の部分だけ抜き出します。

```python
import numpy as np
rng = np.random.default_rng(2026)
P = 0.5  # 真の賛成率

def running_mean(x):
    return np.cumsum(x) / np.arange(1, len(x) + 1)
```

## 実験1：独立（基準）

各人が独立に確率 0.5 で賛成します。

```python
def sample_independent(n, p=P):
    return rng.random(n) < p
```

図1の左がこれです。1,000人の時点で ±3.2 ポイント（理論の ±2σ）に収まり、以降は $\sqrt{n}$ の速さで縮み続けます。ここが基準線です。

## 実験2：束（クラスター）

出口調査や面接調査は、1,000人を全国から1人ずつ選ぶのではなく、地点を選んでその中でまとめて聞きます。同じ地点で聞かれた人たちを「束」と呼びます。束の中の人は、その日その町の空気を共有しているので、答えが似ます。

作りたいのは次の列です。**一人ひとりの賛成確率はどの人も 0.5。ただし同じ束の2人の答えには相関 $\rho$ があり、束が違えば独立。** 実験1と違うのは真ん中の一点だけです。

これをコードでどう作るか。「同じ束の2人が似る」を、**束ごとに共通の値を一つ引いて、束の中の各人はその値を通してつながっている**、という形で実装します。束 $k$ に賛成率 $p_k$ を一つ割り当て、その中の人は $p_k$ で賛成するかどうかを決める。$p_k$ の平均を 0.5 にしておけば、一人ひとりの賛成確率は $E[p_k] = 0.5$ のままです。

ここで、データの裏側を知っているかどうかで見え方が変わります。このシミュレーションを作った側は $p_k$ を知っているので、同じ束の2人は独立に見えます（$p_k$ で各自が決めているだけなので）。$p_k$ を知らない側──調査員や、結果を読む人──から見れば、2人は共通の $p_k$ を通じてつながっているので、相関があります。この記事で扱う相関は後者で、その大きさは

$$
\mathrm{Cov}(X_i, X_j) = E[X_i X_j] - p^2 = E[p_k^2] - p^2 = \mathrm{Var}(p_k)
$$

です（2番目の等号は、$p_k$ を固定すれば独立であることを使っています）。答え1つの分散は $p(1-p)$ なので、同じ束の2人の相関は

$$
\rho = \frac{\mathrm{Var}(p_k)}{p(1-p)}
$$

になります。つまり、**狙った相関 $\rho$ を作るには、$p_k$ の分散を $\rho\,p(1-p)$ にすればよい**。

$p_k$ の分布は、0〜1 の値で平均 0.5、分散だけ調整できるものなら何を使っても同じ $\rho$ になります。ここでは確率を表す分布として標準的なベータ分布を使います。対称な $\mathrm{Beta}(a, a)$ は平均 0.5、分散 $\frac{1}{4(2a+1)}$ なので、$p = 0.5$ のとき $\rho = \frac{1}{2a+1}$、つまり $a = (1/\rho - 1)/2$ と逆算できます。

```python
def sample_cluster(n, m, rho, p=P):
    """1束 m 人。束ごとに賛成率 p_k を引き、束の中は p_k で答える。"""
    k = -(-n // m)                      # 束の数（切り上げ）
    a = (1 / rho - 1) / 2               # 同じ束の2人の相関が rho になる Beta(a, a)
    p_k = rng.beta(a, a, size=k)        # 束ごとの賛成率
    return (rng.random((k, m)) < p_k[:, None]).ravel()[:n]
```

本当に狙いどおりの列になっているかを確かめます。1束100人・相関0.1で20,000束を作り、全体の賛成率と、同じ束の2人・違う束の2人の相関を実測しました。

```
全体の賛成率        0.4992
同じ束の2人の相関   0.0982
違う束の2人の相関   0.0013
```

一人ひとりは 0.5 のまま、同じ束の中だけに相関 0.1 が入っています。

聞く順番は束ごとです。1束1,000人なら、最初の1,000人が $p_1$ を共有し、次の1,000人が $p_2$ を共有し、束と束のあいだは独立です。

図1の中央が1束100人・束の中の相関0.1、右が1束1,000人・相関0.1です。

![束にして聞くと、賛成率の落ち着き方はどう変わるか](/images/fig1_panels.png)
*図1：左から、独立／束100人／束1,000人。各8試行、赤は理論の±2σ、縦の破線は1,000人の時点。*

中央（束100人）は、1,000人の時点で ±10.4 ポイント。独立の3倍以上です。右（束1,000人）は ±31.8 ポイント。1,000人がまるごと一つの束なので、最初の1,000人のあいだ、各線は 50% ではなく**その束の賛成率 $p_k$ に向かって**落ち着いていきます。8本が 30〜70% のばらばらな高さで安定しているのはそのためです。1,001人目から別の $p_k$ を持つ2束目が混ざるので、そこから線が動き出します。

ただし、どちらも右端では 50% に向かっています。**着く場所は変わらず、着く速さだけが落ちている**。これが束の効き方です。

## 実験3：束の効き目は「人数 × 相関」で決まる

束の中の人数 $m$ と相関 $\rho$ を別々に振って、1,000人が実質何人分かを実測してみます。「何人分か」は、独立なら $p(1-p)/n$ になるはずの分散を実測の分散で割った値です。

![束の効き目は、1束の人数と束の中の相関の積で決まる](/images/fig2_m_rho.png)
*図2：左は相関ごとに m を振ったもの。右は横軸を (m−1)×相関 に取り直したもの。線は理論、点は400試行の実測。*

左の図では相関ごとに別の線になりますが、横軸を $(m-1)\rho$ に取り直すと（右の図）、全部が $1000/(1+x)$ の1本に重なります。束を小さくするのと、束の中で似ないようにするのとで、効き目は同じです。100人の束で相関0.1なら、1束はおよそ9人分。

標本設計ではこの $1+(m-1)\rho$ を「設計効果」と呼びます。1地点50人・相関0.1なら約5.9倍で、1,000人は170人分です。

## 1本の式

ここまでを1本にまとめます。答え $X_1, \dots, X_n$ の分散を $\sigma^2$、$i$ 番目と $j$ 番目の相関を $\rho_{ij}$ とすると、標本平均の分散は共分散の総和で

$$
\mathrm{Var}(\bar X) = \frac{1}{n^2}\sum_{i}\sum_{j}\mathrm{Cov}(X_i, X_j)
= \frac{\sigma^2}{n}\Bigl(1 + (n-1)\,\bar\rho\Bigr),
\qquad
\bar\rho = \frac{1}{n(n-1)}\sum_{i \ne j}\rho_{ij}
$$

です。$\bar\rho$ は全員の組について相関を平均したもの（平均相関）。独立なら $\bar\rho = 0$ で、いつもの $\sigma^2/n$ に戻ります。

束の場合、同じ束に入る組の割合は $(m-1)/(n-1)$ なので $\bar\rho = \rho\,(m-1)/(n-1)$。括弧の中は

$$
1 + (n-1)\bar\rho = 1 + (m-1)\rho
$$

で、$n$ によらない定数になります。これが実験3で見た設計効果です。

括弧の中が定数に留まるということは、$n$ で割る分だけは効いて、遅れても着く、ということです。1束の人数が決まっていれば、聞く人数を増やした分は別の束の人になるので、独立な組ばかりが増えて平均相関はゼロに向かう。**独立が崩れても、平均相関がゼロに向かうかぎり、大数の法則は速さを失うだけで行き先は失わない。**

これを実測と突き合わせます。6通りの束の作り方で、1,000人の平均を2,000回ずつ取り、分散から「何人分か」を出しました。

## 何が言えなくなり、何がまだ言えるか

言えなくなるのは、誤差が $\sqrt{n}$ で縮むという速度の見積もりです。「1,000人だから±3」は、束の作り方を見ずには言えません。

まだ言えるのは、行き先です。束の選び方に偏りがなく、1束の人数が決まっているかぎり、平均は真の値に着きます。そして速度の方も、束の人数と相関さえ見積もれれば $1 + (m-1)\rho$ で補正できる。実務が設計効果を使っているのはそのためです。

ただし、この記事で扱ったのは「平均相関がゼロに向かう」場合だけです。1,000人全員が一つの束で、しかも人数を増やしても束が増えない──平均相関がゼロに向かわない──とき、式の括弧の中は $n$ とともに育ちます。そこでは平均は落ち着くのに、真の値ではない場所に落ち着く。それは別の記事にします。

もう一つ、独立の崩し方は束だけではありません。隣は似る、少し離れると少し似る、遠くなるとほぼ独立、という距離で減衰する相関も、同じ式の $\bar\rho$ を変えるだけで扱えます。こちらも次の記事で。
